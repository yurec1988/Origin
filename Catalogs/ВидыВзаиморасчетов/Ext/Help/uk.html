Довідник "Види взаєморозрахунків"

Довідник призначений для додаткового поділу взаєморозрахунків для аналізу даних у звітах.

За допомогою цього довідника можна провести додаткову класифікацію однотипних договорів різних контрагентів.

Наприклад, для довгострокових договорів установити вид взаєморозрахунків - довгострокові, а для разових договорів установити вид взаєморозрахунків - разові.
