Довідник "Настройка бізнес-процесів"

Довідник "Настройка бізнес-процесів" слугує для зберігання інформації про параметри задач для кожної точки маршруту бізнес-процесу.

Обов'язковою є зазаначення виду бізнес-процесу, для якого буде використовуватися ця настройка. Після того, як настройку використовували в будь-якому з процесів, вид настройки змінювати не можна.

>Для настройки з видом бізнес-процесу "Погодження замовлення покупця" обов'язковим є зазначення виконавців задач для кожної точки дії карти маршруту. Для видів бізнес-процесів "Переоцінка товарів у роздробі","Переоцінка товарів в АТТ" виконавців визначають алгоритмічно, і в довіднику їх не вказують.

Для виду бізнес-процесу "Переоцінка товарів у роздробі " необхідно вказати настройку для точки вкладеного бізнес-процесу "Переоцінка товарів в АТТ".

Для кожного виду бізнес-процесу може бути створено необмежену кількість настройок.
