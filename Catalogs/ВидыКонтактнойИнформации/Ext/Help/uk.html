Довідник "Види контактної інформації"

Довідник слугує для класифікації контактної інформації різних об'єктів системи.

Для кожного виду контактної інформації визначено тип контактної інформаціїіз закладеного в системі фіксованого списку, і тип об'єкта, для якого цей вид контактної інформації буде використовуватися.

Наприклад, для контактної інформації типу "Адреса" для об'єктів довідника "Фізичні особи" можна визначити такі види контактної інформації як "Домашня адреса" або "Робоча адреса", а для об'єктів довідника "Контрагенти" - "Юридична адреса" або "Поштова адреса".

Деякі елементи довідника "Види контактної інформації" є напередвизначеними і не видаляються користувачами.
