Настройка джерела даних

Настройка джерела даних виконується для наборів даних типу "Об'єкт". Джерела даних призначені для заповнення даними набору даних.

Джерело даних може бути таких типів:

  • Звіт. Вибирається звіт зі списку звітів конфігурації на базі універсального або на базі типового звітів.
  • Довільний звіт. Вибирається звіт зі списку довільних звітів.
  • Зовнішня обробка. Вибирається зовнішня обробка.

Під час вибору джерела даних автоматично заповнюються параметри. У списку парметрів допускається редагування імені параметра схеми.

Під час натискання на кнопку "ОК" виконується заповнення полів набору даних і параметрів схеми компонування.

Вимоги до зовнішньої обробки

Обробка повинна містити

  • Функция ПолучитьДанные(ПараметрыИсточникаДанных, НастройкиКомпоновкиДанных) . Функція призначена для отримання даних джерела даних.
    Де,
    • ПараметрыИсточникаДанных - таблиця значень (див"Процедура ЗаповнитиСписокПараметрів")
    • НастройкиКомпоновкиДанных - налаштування компонування даних
  • Процедура ЗаполнитьСписокПолей(СписокПолейИсточника). Процедура призначена для заповнення списку полів джерела даних. Викликається для заповнення полів набору даних схеми компонування даних.
    Де,
    • СписокПолейИсточника - таблиця значень, що містить колонки: "Поле", "Заголовок", "ТипЗначения", "ВыражениеПоляИтога", "ЭтоРесурс".
  • Процедура ЗаполнитьСписокПараметров(СписокПараметровИсточника) . Процедура призначена для заповнення списку параметрів джерела даних. Викликається для заповнення параметрів.
    Де
    • СписокПараметрівДжерела - таблиця значень, що містить колонки: "Имя", "Заголовок", "ОграничениеИспользования", "Выражение", "ТипЗначения".
