Довідник "Класифікатор кодів для ПН"

У цьому довіднику зберігається список кодів товарів і послуг для використання в податкових документах: коди УКТЗЕД для товарів і коди ДКПП для послуг.

Підбір кодів із класифікаторів УКТЗЕД і ДКПП здійснюється при натисканні відповідних кнопок. При виборі (ручному введенні) коду УКТЗЕД обирається Вид: Товар або Імпортований товар. Для імпортованого товару в графі 3.2 Податкової накладної проставляється відмітка Х. Якщо підприємство здійснює поставку імпортних і вітчизняних товарів з одним і тим самим кодом УКТЗЕД, код має бути внесений до класифікатора двічі: як Товар та Імпортований товар. При виборі (ручному введенні) коду ДКПП зазначається Вид Послуга.

Для окремих видів сільськогосподарської продукції, для яких передбачено особливий порядок виписки податкових документів, встановлюється прапор До товару застосовується режим експортного забезпечення.
