Довідник "Зовнішні обробки, друковані форми, обробки по заповненню табличних частин"

Довідник містить список довільних обробок, додаткових друкованих форм, обробок для заповнення ТЧ об'єктів.

Загальний опис


Довільна обробка.

Для довільних обробок необхідно вказувати тільки зовнішню обробку, яка знаходиться на диску, для її завантаження в реквізит елемента довідника. Так само для довільних обробок необхідно мати можливість призначати права доступу для їх використання.

Обробка для заповнення ТЧ об'єктів.

Для обробок заповнення ТЧ необхідно вказувати зовнішню обробку, список об'єктів і їхніх ТЧ, для яких необхідно використовувати цю обробку.

Зовнішня друкована форма.

Для зовнішніх друкованих форм, що підключаються, необхідно вказувати:

  • зовнішню обробку
  • за необхідності, можна вказати список додаткових параметрів, які будуть передаватися зовнішній обробці
  • список об'єктів, для яких ця друкована форма використовується
  • для кожного об'єкта кілька доборів, під час виконання яких друкована форма стає доступною для використання з цим об'єктом
  • для кожного об'єкта свою окрему друковану форму, але в списках друкованих форм в об'єктах завжди з'являтиметься однаковий пункт підменю
  • для кожного об'єкта вбудовану друковану форму, яка буде замінена зазначеною зовнішньою

Коректно зареєстрована друкована форма буде виводитися в загальному списку друкованих форм об'єкта, що викликається за кнопкою "Друк". При цьому форма буде поміщена в кінець цього списку, відокремлена роздільником. Якщо друкована форма, що підключається, замінює стандартну, то вона замінюється і показується в списку стандартних друкованих форм.

У формі списку довідника можливе виконання перенесення всіх зареєстрованих додаткових друкованих форм між різними базами. Виклик форми перенесення здійснюється за допомогою кнопки "Експорт / імпорт". У цій формі слід вказати ім'я файлу, в якому (з якого) буде збережено (отримано) список форм. Збереження списку у файлі здійснюється натисканням кнопки "Експорт", відповідно отримання - "Імпорт".

Вимоги до підключення зовнішніх обробок:


Довільна обробка.

Будь-яка зовнішня обробка, з певною основною формою.

Обробка для заповнення ТЧ об'єктів.

Зовнішня обробка, що містить:

  • Необов'язковий реквізит "ДополнительныеПараметры" довільного типу, якому будуть передаватися додаткові параметри примітивного типу у вигляді структури.
  • У модулі експортну процедуру: Инициализировать(Объект,ИмяТабличнойЧасти,ТабличноеПолеОбъекта)

де:

  • Объект. – ДокументОбъект, СправочникОбъект. Звідки був зроблений виклик процедури заповнення зовнішньої обробки;
  • ИмяТабличнойЧасти - Рядок. Ім'я табличної частини, для якої викликано обробку.
  • ТабличноеПолеОбъекта - Елемент форми: Табличне поле. Табличне поле форми, для якого викликано обробку.

А так само може мати у своєму складі :
макет "Параметры_Авторегистрации", який використовується для автоматичного заповнення приналежності друкованої форми в довіднику "Зовнішні обробки", що складається з 2-х колонок - "повне ім'я метаданого" і "ім'я табличної частини"

Зовнішня друкована форма.

Зовнішня обробка, що містить:

  • Необов'язковий реквізит "ДополнительныеПараметры" довільного типу, якому будуть передаватися додаткові параметри примітивного типу у вигляді структури.
  • Реквізит "СсылкаНаОбъект", в який при виклику буде передано посилання на об'єкт, для якого необхідно виконати друк.
  • Функція "Печать()" - без параметрів, що повертає табличний документ.

макет "Параметры_Авторегистрации", який використовується для автоматичного заповнення приналежності друкованої форми в довіднику "Зовнішні обробки", що складається з 2-х колонок - "повне ім'я метаданого" і "ім'я табличної частини"
