Довідник "Характеристики номенклатури"

У конфігурації можна вести кількісний облік у розрізі різних характеристик номенклатури.

Важливо. Ведення обліку за характеристиками не є обов'язковим. Вести чи ні облік за характеристиками, визначається в настройках параметрів обліку ("Використовувати характеристики номенклатури").

Характеристики номенклатури заповнюються в довіднику "Характеристики номенклатури", підпорядкованому довіднику номенклатури.

Характеристики призначаються тільки для тих позицій, у яких встановлено прапорець "Вести облік за дод.характеристиками".

Довідник "Характеристики номенклатури" містить усі можливі описи характеристик для обраної позиції номенклатури.

Опис позиції номенклатури складається зі списку значень певних видів властивостей. Причому для різних груп номенклатури можуть бути визначені різні види властивостей.

Наприклад. Для опису характеристик товарів групи "Взуття" можуть бути використані такі види властивостей, як розмір, колір, повнота. Для опису товарів групи "Холодильники" використовуються такі види властивостей, як габарити, об'єм морозильної камери, колір оздоблення.

Види властивостей задаються в об'єкті "Плани види характеристик". Інформацію в об'єкті "Плани видів характеристик" можна заповнити заздалегідь або під час введення нової характеристики для позиції номенклатури.

Для того щоб додати нову характеристику для позиції номенклатури, необхідно виконати такі дії:

  • Установити курсор на потрібну позицію номенклатури в довіднику.
  • На панелі управління необхідно натиснути кнопку "Перейти";
    Зі списку, що випадає, вибрати пункт меню "Характеристики номенклатури". З'явиться діалогове вікно, в якому будуть перераховані значення видів властивостей, задані для позиції номенклатури.
  • Додати нову характеристику. Додавання нової характеристики здійснюється стандартним чином під час натискання клавіші "INS" або шляхом вибору відповідної піктограми на панелі керування. При цьому відкриється діалогове вікно, в якому будуть перераховані всі види властивостей, визначені для цієї позиції номенклатури в об'єкті "Плани видів характеристик".
  • Для кожної властивості необхідно вибрати значення зі списку визначених для цієї властивості значень. Якщо такого значення немає в списку, то його можна додати.

У полі "Найменування" за введеними значеннями властивостей буде сформована нова характеристика товару. При натисканні на кнопку "ОК" цю характеристику буде перенесено в довідник "Характеристики номенклатури" для цієї позиції номенклатури.

При занесенні характеристики перевіряється її унікальність. Якщо така характеристика вже є у позиції номенклатури, то повторно вона занесена не буде.
Безпосередньо з діалогу введення характеристик можна додати нову властивість в об'єкт"План видів характеристик".

Під час підбору позицій номенклатури в документ показуються залишки товарів у розрізі різних характеристик. Нову характеристику для позиції номенклатури може бути додано і в момент оформлення документа, наприклад, під час надходження товару на склад.
