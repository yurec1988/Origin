Обробка "Вивантаження даних у форматі CommerceML"

Обробка "Вивантаження даних у форматі CommerceML" призначена для формування електронних документів відповідно до вимог другої редакції стандарту CommerceML.

Вивантаження даних може виконуватися або в безпосередньо файл, або у вкладення електронного листа. Якщо вивантаження ведеться у файл, необхідно заповнити ім'я файлу для передачі інформації про товари або ім'я каталогу для передачі електронних документів, у який здійснюватиметься вивантаження. У режимі вивантаження "Вивантажити дані електронною поштою" обробка формує документи "Електронний лист" і елементи довідника "Вкладення електронних листів".

Для вивантаження каталогу товарів необхідно вибрати в списку видів вивантаження значення "Інформація про товари (каталог товарів)" та організацію - власника каталогу товарів. У реквізиті "Ім'я каталогу" можна вказати найменування каталогу товарів, у разі, якщо реквізит не заповнений, то найменування каталогу буде створено системою за замовчуванням. За допомогою табличного поля "Поля відбору для каталогу" можна налаштувати фільтр для вивантаження позицій номенклатури. Якщо поля відбору не вибрано, то в каталог буде вивантажено всі номенклатурні позиції. Під час вивантаження для надсилання електронною поштою створюється новий документ "Електронний лист" і відкривається форма нового документа.

Для вивантаження прайс-листа (пакета пропозицій) необхідно вибрати в списку видів вивантаження значення "Прайс-лист". У реквізиті "Ім'я прайса" можна вказати найменування каталогу товарів, у разі якщо реквізит не заповнений, то найменування каталогу буде створено системою за замовчуванням. За допомогою табличного поля "Поля відбору для прайса" можна налаштувати фільтр для вивантаження позицій номенклатури і фільтр для типів цін, що вивантажуються. Якщо поля відбору не вибрано, то в каталог буде вивантажено ціни всіх типів за всіма номенклатурними позиціями. Під час вивантаження для надсилання електронною поштою створюється новий документ "Електронний лист" і відкривається форма нового документа.

Для вивантаження документів необхідно вибрати в списку видів вивантаження відповідний документ. Вивантаження здійснюється за підібраними документами. Для підбору документів використовуйте список документів. Список має вигляд дерева з двома рівнями - контрагент і документи контрагента. Для заповнення дерева використовуйте реквізити відбору періоду дат документів і реквізити обора контрагентів. Заповнення списку відбувається під час натискання кнопки "Заповнити". Якщо поточний режим вивантаження передбачає формування електронного листа, то відбирають тільки документи за контрагентами, які мають "Адреса електронної пошти для обміну електронними документами". Якщо вивантаження здійснюється в режимі "Вивантажити дані у файл" - усі вибрані документи буде записано в один XML-файл. Якщо використовується режим "Вивантажити дані електронною поштою", для кожного контрагента буде сформовано окремий XML-файл. Цей файл буде приєднано як вкладення до відповідного документа "Електронний лист". Після генерації всіх листів система пропонує здійснити відправлення листів.

УВАГА!!!
Програма підтримує обмін тільки для номенклатури, у якій встановлено тип "Товар". Для будь-яких інших типів номенклатури обмін даними не виконується. Це стосується як інформації про номенклатуру, прайс-лист, так і про товари в документах.

Для запуску механізмів вивантаження необхідно натиснути кнопку "Вивантажити дані". У разі значного обсягу товарних позицій, що вивантажуються, обробка може зайняти тривалий час.
