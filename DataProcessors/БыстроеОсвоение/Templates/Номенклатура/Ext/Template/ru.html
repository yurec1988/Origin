Заповнення відомостей про товари і послуги  

1. Відкрийте список номенклатури (товарів і послуг) торгового підприємства.
Для цього в меню Довідники виберіть пункт Номенклатура і підпункт Номенклатура.
 

ПРИМІТКА
Номенклатура в програмному продукті — це перелік товарів і послуг. Також передбачена можливість зберігання наборів товарів. Набори товарів можуть використовуватися для оформлення швидкого продажу товарів без попереднього збирання (набір-комплект) и для швидкого заповнення табличної частини документа (набір-пакет).   

Для класифікації товарів в довіднику "Номенклатура" створюються групи і підгрупи товарів.

При початковому заповненні в довіднику "Номенклатура" вже створено кілька груп. Для них налаштовані рахунки бухгалтерського обліку по умовчанню. Група "Товари" відсутня, тому що рахунок 281 по умовчанню налаштований для всіх товарів, які не входять у створені групи. Тому для товарів створюються нові групи, для таких товарів в документах буде зазначатися рахунок 281. 

ПОРАДА
Структура груп має бути створена таким чином, щоб надалі використовувати групи для швидкого пошуку товарів у процесі оформлення документів і для аналізу даних у звітах.

Нові групи і елементи в довіднику Номенклатура створюються так само, як в довіднику Контрагенти (див. розділ "Заповнення відомостей про діловіх партнерів торгового підприєства").

2. Введіть в довіднику Номенклатура групу товарів "Побутова техніка", зазначте для неї Вид номенклатури "Товар". Для цього в полі Вид номенклатури натисніть на кнопку вибору , відкриється список Види номенклатури. Додайте вид номенклатури натисканням кнопки  (або натисніть клавішу Insert або виберіть пункт меню Дії - Додати). Додайте вид номенклатури з Типом номенклатури Товар:


Аналогічним чином введіть групу товарів "Продукти". 

3. Для групи товарів "Побутова техніка" створіть дві підгрупи: "Кондиціонери" і "Телевізори". Для них також зазначте Вид номенклатури "Товар".

4. Створіть в групі "Кондиціонери" номенклатуру "Кондиціонер SAMSUNG". Зазначте Базову одиницю "шт.". Натисніть кнопку Записати.

ПРИМІТКА
Для того, щоб при введенні нової номенклатурної картки автоматично заповнювалися Базова одиниця, необхідно в настройках користувача (Сервіс - Параметри користувача) в групі настройок Основні значення для підставляння в документи і довідники зазначити значення за замовчуванням.  

5. Якщо організація є платником ПДВ, зазначте Ставку ПДВ, за якою зазвичай оподатковується товар.

Зазначте код УКТЗЕД, що буде підставлятися в податкові накладні. Для цього потрібно натиснути кнопку вибору  біля реквізиту Код для ПН (по умовчанню) і вибрати варіант Вибрати із класифікатора.

Відкривається "Класифікатор кодів для ПН", який можна заповнити за кнопкою Підбір з УКТЗЕД. При виборі кодів, які продаються підприємством, можливий пошук за клавішею Ctrl - F.


Зазначте код УКТЗЕД в класифікаторі і в номенклатурній картці. Збережіть номенклатурну картку за кнопкою ОК.

ПОРАДА
Додаткова інформація про товар (послуга) вводиться на різних закладках. За кнопкою Настройка можна налаштувати видимість закладок і розташованих на них полів (реквізитів). Також можна налаштувати обов'язковість заповнення тих чи інших реквізитів довідника Номенклатура. Для кожного користувача програми можна встановити свої настройки і зберегти їх.

6. Аналогічним чином створіть в групі "Телевізори" номенклатуру "Телевізор Samsung".

7. Створіть в групі "Продукти" номенклатуру "Печиво бісквітне" з Базовою одиницею кг.

Товар може продаватися як на вагу, так і в упаковках по 0.5 кг.

На закладці Одиниці додайте нову одиницю вимірювання. Для неї необхідно зазначити значення За класифікатором за кнопкою вибору . Відкриється "Класифікатор одиниць вимірювання", який можна заповнити за кнопкою Підбір із класифікатора.

 

8. Додайте в класифікатор одиницю вимірювання "паков", додайте її для номенклатурі на закладці Одиниці. Зазначте для нової одиниці вимірювання Коефіцієнт 0,5.

9. Для групи "Послуги" зазначте Вид номенклатури "Послуга" типу Послуга, для цього внесіть Вид номенклатури "Послуги" в довідник:  

10. Створіть в групі "Послуги" номенклатуру "Доставка".
