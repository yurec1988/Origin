Головне вікно консолі звітів.

У головному вікні консолі звітів розташовані:

  • Головна командна панель, на якій розташовані команди для створення нового файлу звітів, збереження файлу звітів, завантаження файлу звітів.
  • Дерево звітів. У цьому списку розташовуються звіти, які користувач може виконувати. Робота зі зміни складу звітів здійснюється за допомогою контекстного меню, що викликається правою клавішею миші.
  • Праворуч від дерева звітів розташовується панель настройок, у якій здійснюється настройка звіту. Для настройок використовуються такі закладки:
    • Відбір - на цій закладці розташовується табличне поле для редагування відбору (фільтра) даних, що виводяться у звіт.
    • Групування - містить два табличних поля для настройки групувань звіту. Одне для настройки групувань у рядках, одне для групувань у колонках.
    • Порядок - містить табличне поле для настройки порядку виведення звіту
    • Поля - містить табличне поле для настройки полів, що видаються у звіт
    • Оформлення - містить настройки оформлення звіту
  • Більшу частину форми займає панель результату, що розташована в нижній частині форми.

Виконання звіту

Для виконання звіту необхідно вибрати звіт, який вас цікавить, у дереві звітів, натиснути на одну з кнопок "Вивести в таблицю", "Вивести в діаграму", "Вивести в зведену таблицю", розташованих на головній командній панелі консолі. Після чого буде виконано звіт і виведено в табличний документ, діаграму або зведену таблицю відповідно. У разі виведення у зведену таблицю, для відображення результату необхідно після натискання на кнопку "Виконати" розташувати на зведеній таблиці цікаві для вас вимірювання та ресурси.

Розшифровка звіту

Для розшифровки звіту необхідно в результаті натиснути Enter або зробити подвійне настискання на групуванні, що цікавить. Після чого користувачу буде запропоновано діалог з вибором звіту, що виконує розшифровку. У разі, якщо користувач вибере для розшифровки поточний звіт, то йому буде запропоновано для вибору список групувань, якими можна розшифрувати поточний звіт. Після вибору звіту та групування програма сформує звіт і виведе його на поточну закладку панелі результату.

Історія звітів

Для навігації за раніше виконаними звітами необхідно натиснути на кнопку "Назад" командної панелі звіту. Для переходу до наступного виконаного звіту - кнопку "Вперед".

Настройка відбору

Настройка відбору здійснюються в табличному полі "відбір". Тут можна додати елемент відбору, відредагувати наявний, видалити елемент відбору.

Настройка групувань

Для настройки групувань слід користуватися табличними полями, розташованими на закладці "Групування". Тут можна додати групування звіту, видалити, поміняти їх місцями.

Настройка порядку

Настройка порядку здійснюється на закладці "Порядок". Тут необхідно вибрати поля, за якими необхідно здійснити впорядкування. Поля слід розташувати в тому порядку, в якому необхідно впорядкувати результат.

Настройка полів

Настройка полів здійснюється на закладці "Поля". Для настройки слід у табличне поле, розташоване в правій частині закладки, внести поля, які потрібно вивести у звіт.

Настройка оформлення

Настройка оформлення звіту здійснюється на закладці "Оформлення". У консолі звітів передбачено такі настройки оформлення:

  • Варіант оформлення - набір колірних оформлень звіту
  • Розміщення групувань - тип розміщення групувань відносно одне одного. Можливі варіанти:
    • Розміщення групувань в одній колонці/рядку.
    • Розміщення групувань в окремих колонках
    • Розміщення групувань в окремих колонках, причому підписи групувань відображаються тільки в підсумкових рядках
  • Розміщення реквізитів групувань - тип розміщення реквізитів групувань (таких, наприклад, як код номенклатури, її ціна). Можливі варіанти:
    • Разом з групуваннями - у цьому варіанті реквізити розміщуються в одній комірці з і групуваннями.
    • Окремо - для кожного реквізиту виділяється своя колонка
    • Разом - усі реквізити розташовуються в окремій колонці, окремо від групувань.
  • Розміщення підсумків. Варіант відображення підсумків. Можливі такі значення:
    • У заголовку - підсумкові значення відображаються в рядку з групуваннями
    • У підвалі - підсумкові рядки розміщуються в підвалі групування.
  • Фіксований макет - налаштовується макет, відповідно до якого буде видаватися звіт.
