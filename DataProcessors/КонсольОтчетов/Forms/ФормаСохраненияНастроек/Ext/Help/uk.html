Форма збереження настройки

Форма збереження настройки призначена для збереження параметрів виведення звіту.

На формі розташовані:

  • Поле введення для встановлення імені настройки, що зберігається
  • Прапорець "Використовувати під час відкриття", що позначає необхідність відкриття настройки під час відкриття
  • Список раніше збережених настройок.
  • Прапорець "Зберігати настройки автоматично", за допомогою якого можна позначити необхідність автоматичного збереження настройок звіту.
  • Кнопки
    • ОК - для збереження настройки під ім'ям, введеним у полі введення "Найменування настройки".
    • Скасування - для скасування всіх виконаних дій.
    • Видалити - для видалення настройки, виділеного в списку настройок.
    • Довідка - для виведення довідкової інформації
