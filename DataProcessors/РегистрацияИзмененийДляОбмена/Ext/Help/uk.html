Обробка "Реєстрація змін для обміну"

Обробка "Реєстрація змін для обміну" дає змогу:

1. Переглядати список метаданих, що беруть участь в обміні

2. Переглядати список об'єктів для яких зареєстровані зміни. Для цього потрібно встановити прапорець "Завантажувати зміни" та натиснути на кнопку "Зареєстровані зміни"

3.Видаляти у знімати реєстрацію для об'єктів. Для посилальних даних можна інтерактивно вибирати список об'єктів для встановлення реєстрації, а також використовувати запити для вибору даних

4. реєструвати по одному об'єкту кожного типу. Цей функціонал може використовуватися для налагоджувальних цілей роботи обміну даними

5. Переглядати XML стандартного вивантаження довільного об'єкта

Обробка призначена для розробників обміну даними в довільних конфігураціях.
