Розшифровка регламентованої звітності

Для форм регламентованої звітності, які можуть заповнюватися автоматично за даними інформаційної бази, існує можливість показати алгоритм формування значень показників звіту. Такий режим називається "розшифровкою". Режим доступний не для всіх форм звітності: формальною ознакою можливості розшифровки для конкретного регламентованого звіту є присутність кнопки"Розшифровка" у верхній командній панелі форми звіту. Розшифровка доступна після того, як звіт автоматично заповнено за даними інформаційної бази. Інформація для розшифровки накопичується в процесі автозаповнення звіту.

Форма розшифровки містить таблицю з алгоритмом обчислення значення показника, для якого викликано розшифровку, або декілька таблиць - для всіх показників форми звітності. Кожен рядок таблиці містить опис одного зі складників і значення цього складника. Підсумкове значення показника видається в нижній частині таблиці.

Форма розшифровки може мати кілька закладок для різних показників, якщо розшифровку викликали кілька разів.

З розшифровки можна викликати стандартні звіти для більш детального розкриття сум звіту. Якщо під час розміщення курсору миші на суми у вікні розшифровки курсор набуває вигляду лупи, тоді подвійним настисканням миші буде викликано один зі стандартних звітів - оборотно-сальдова відомість за рахунком або аналіз рахунка, який містить дані рахунка/корахунка, які брали участь у формуванні поточного доданкового значення показника.

У нижній командній панелі форми розшифровки розташовано низку кнопок для управління розшифровкою.

"Активізувати батьківський звіт" - кнопка активізує звіт, для якого було викликано цю розшифровку.

"Друк" - після натискання цієї кнопки видається запит для вибору, розшифровку яких показників слід друкувати. Після встановлення прапорців для необхідних показників і натискання кнопки "ОК" буде сформовано друковані форми для обраних показників.

"Зберегти" - кнопка дає змогу зберегти розшифровку у вигляді файлу формату табличного документа платформи.

"Закрити" - закриває вікно розшифровки.
