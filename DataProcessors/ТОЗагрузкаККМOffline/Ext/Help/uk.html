Обробка "Завантаження даних в ККМ, що підключаються в режимі Offline"

Ця обробка обслуговування призначена для завантаження списку товарів у ККМ, що підключені в режимі Offline. При використанні цієї обробки передбачається такий порядок дій:

Ця обробка обслуговування призначена для завантаження списку товарів у ККМ, що підключені в режимі Offline. При використанні цієї обробки передбачається такий порядок дій:

  • Редагування списку вивантаження - необхідно задати список товарів, що підлягають вивантаженню в ККМ. У процесі редагування цього списку кожному товару присвоюється ідентифікатор (PLU), який буде присвоєно цьому товару на касі. Для переходу до цього списку необхідно натиснути кнопку "Редагувати список вивантаження" верхньої командної панелі форми обробки.
  • Вибір складу - зазначення складу необхідне для визначення ціни товарів. Для зазначення складу використовується поле вибору "Склад", розташоване у верхній частині форми обробки.
  • Вибір ККМ - для вибору ККМ, підключеної в режимі Offline, використовується поле вибору "ККМ Offline", розташоване у верхній частині форми обробки.
  • Вибір типу цін - тип цін використовується для визначення ціни товарів. Для його зазначення використовується поле введення "Тип цін", розташоване у верхній частині форми обробки.
  • Редагування параметрів заповнення - під час заповнення таблиці товарів, що вивантажуються, можна вказати необхідність вивантаження тільки тих товарів, які є на заданому складі. Для використання цієї можливості необхідно використовувати прапорець "Тільки наявні на складі", розташований у верхній частині форми обробки.
  • Заповнення таблиці товарів, що вивантажуються - для виконання цієї дії необхідно натиснути кнопку "Заповнити", розташовану у верхній командній панелі форми обробки.
  • Вивантаження товарів - для виконання цієї дії необхідно натиснути кнопку "Завантажити в ККМ", розташовану у верхній командній панелі форми обробки.
