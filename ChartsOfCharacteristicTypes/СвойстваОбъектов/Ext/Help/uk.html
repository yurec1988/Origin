Заповнення видів і значень властивостей об'єктів

Для кожного об'єкта можуть бути призначені значення видів властивостей різного типу. Значення видів властивостей заносяться за допомогою обробки "Властивості об'єктів".

Для властивості об'єктів можуть бути призначені різні типи значення властивостей.
На етапі конфігурування в список властивостей об'єктів можуть бути додані напередвизначені значення властивостей, категорій або характеристик.

У процесі роботи з типовою конфігурацією користувач може додавати властивості, що мають різні типи значень.
Додавання нового виду властивості відбувається в окремому діалоговому вікні, яке відкривається під час натискання на клавішу INS або під час вибору відповідної піктограми на панелі керування.

У формі елемента вводиться інформація про найменування властивості, що вводиться, визначається призначення і тип значень для цієї властивості.

Діалогове вікно складається з двох закладок.

  • На закладці "Призначення властивості" можна вказати конкретні об'єкти або групи об'єктів, для яких буде призначено дану властивість. Так, наприклад, вид властивості розмір доцільно призначити для групи "Взуття".
    У список об'єктів, для яких призначено властивість, можна додати кілька груп номенклатури або навіть вибрати конкретні позиції номенклатури, якщо властивість, що призначається, має сенс тільки для конкретних позицій номенклатури. Якщо до списку об'єктів, для яких призначено властивість, не обрано жодного елемента, то цю властивість призначають усім об'єктам зазначеного на першій закладці довідника.
  • На закладці "Значення властивості" вводиться список можливих значень для цього виду властивості.
