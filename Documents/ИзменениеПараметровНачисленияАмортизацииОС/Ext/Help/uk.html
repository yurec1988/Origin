Документ "Зміна параметрів нарахування амортизації"

Документ "Зміна параметрів нарахування амортизації" призначений для відображення змін у регістрі відомостей про об'єкти основних засобів для цілей бухгалтерського та податкового обліку.

До документа вносяться нові відомості про об'єкти основних засобів (наприклад, новий строк корисного використання в разі його зміни, вартість для нарахування амортизації або обсяг продукції (робіт) тощо).

Для більш швидкого заповнення табличної частини документа необхідно скористатися кнопкою "Підбір".

Після формування списку основних засобів, що готуються до передачі, необхідно скористатися кнопкою "Заповнити" для заповнення табличної частини інформацією про об'єкти основних засобів за даними обліку, що існують на момент введення документа.

Для швидкого заповнення табличної частини однотипними об'єктами основних засобів, що мають однакові найменування, слід ввести в табличну частину хоча б один такий об'єкт. Потім слід скористатися кнопкою Заповнити в командній панелі табличної частини. При виборі у випадаючому меню пункту За найменуванням таблична частина буде заповнена об'єктами основних засобів, що мають таке саме найменування, як у введеного спочатку.

Під час проведення документа ці відомості записуються в регістр і використовуються документом "Закриття місяця" під час нарахування амортизації в місяці, наступному за місяцем зміни параметрів.

Цей документ не формує жодних проводок, він лише змінює значення відповідних ресурсів регістрів відомостей, що зберігають інформацію про основні засоби.

Для зміни інших характеристик обліку основних засобів (наприклад - способу відображення витрат на амортизацію, графіків нарахування амортизації тощо) використовуються інші документи - "Зміна графіків амортизації ОЗ", "Зміна способів відображення витрат на амортизацію"...
