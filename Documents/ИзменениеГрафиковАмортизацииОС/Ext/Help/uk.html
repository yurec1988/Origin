Документ "Зміна графіків амортизації ОЗ"

Документ "Зміна графіків амортизації ОЗ" використовується для зміни річного графіка амортизації за основними засобами, за якими для нарахування амортизації використовується лінійний спосіб.

Об'єкти, за якими встановлюється графік амортизації, обираються з довідника "Основні засоби".
Для більш швидкого заповнення табличної частини документа необхідно скористатися кнопкою "Підбір".

Під час проведення документа ці відомості записуються в регістр і використовуються документом "Закриття місяця" під час нарахування амортизації в місяці, наступному за місяцем зміни графіка розподілу амортизації.

Цей документ не формує жодних проводок, він лише змінює значення відповідних ресурсів регістра відомостей ("Графіки амортизації бухгалтерський облік").

Для зміни інших характеристик обліку основних засобів (наприклад - способу відображення витрат з амортизації, графіків нарахування амортизації тощо) використовуються інші документи - "Зміна параметрів нарахування амортизації ОЗ", "Зміна способів відображення витрат з амортизації" ...

Для швидкого заповнення табличної частини однотипними об'єктами основних засобів, що мають однакові найменування, слід ввести в табличну частину хоча б один такий об'єкт. Потім слід скористатися кнопкою Заповнити в командній панелі табличної частини. При виборі у випадаючому меню пункту За найменуванням таблична частина буде заповнена об'єктами основних засобів, що мають таке саме найменування, як у введеного спочатку.
