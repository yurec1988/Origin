Документ "Виробіток для розрахунку амортизації НМА"

Документ слугує для відображення фактичного обсягу продукції (робіт) для НМА з нарахуванням амортизації способом списання вартості пропорційно обсягу продукції (робіт).

Дані про фактичний обсяг продукції (робіт) записуються до спеціального регістра накопичення "Виробіток НМА" і використовуються надалі при нарахуванні амортизації за поточний період.

Цей документ не формує жодних проводок, він лише змінює значення відповідних ресурсів регістра накопичення. Використовується для управлінського та бухгалтерського обліку.
