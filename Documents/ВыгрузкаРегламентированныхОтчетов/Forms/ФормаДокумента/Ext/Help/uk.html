Документ "Вивантаження регламентованих звітів"

Документ "Вивантаження регламентованих звітів" призначено для візуалізації текстів вивантаження даних звітності у формат ДПАУ, затверджений наказом ДПАУ від 03.05.2006 № 242, та формат АРМа, розробленого ФСС на випадок тимчасової втрати працездатності, затвердженого Постановою Правління ФСС від 03.03.2006 № 7 (файли з розширенням *.xml).

Документ має службовий характер і не призначений для самостійного використання. Документ автоматично створюється щоразу під час вивантаження даних звітності, що здійснюється за кнопками "Вивантажити у формат ДПАУ (у файл *.xml)" ("Вивантажити у формат АРМу (у файл *.xml)"), розташованими в діалоговій частині форм відповідних звітів.
