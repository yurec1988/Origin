Документ "Модернізація НМА"

Документ "Модернізація НМА" призначений для відображення в обліку модернізації (реконструкції) нематеріальних активів для цілей управлінського, бухгалтерського та податкового обліку.

У шапці документа вносять відомості про об'єкт будівництва, з якого списують витрати з модернізації, для бухгалтерського і податкового обліку - рахунок обліку витрат, а також суми модернізації, окремо для кожного з видів обліку.

Суму модернізації можна отримати автоматично - при натисканні кнопки "Розрахувати суми" суми модернізації заповняться автоматично за даними обліку на момент формування документа. За необхідності ці суми можна відкоригувати вручну.

У табличній частині "Нематеріальні активи" зазначаються об'єкти нематеріальних активів, які модернізуються (реконструюються).

Для більш швидкого заповнення табличної частини документа необхідно скористатися кнопкою "Підбір".

Після формування списку нематеріальних активів необхідно скористатися кнопкою "Заповнити" для заповнення табличної частини інформацією про об'єкти нематеріальних активів за даними обліку, що існують на момент введення документа, а також для розподілу сум модернізації.

Для швидкого заповнення табличної частини однотипними об'єктами нематеріальних активів, що мають однакові найменування, потрібно ввести в табличну частину хоча б один такий об'єкт. Потім слід скористатися кнопкою Заповнити в командній панелі табличної частини. При виборі у меню, що випадає, пункту За найменуванням таблична частина буде заповнена об'єктами нематеріальних активів, що мають таке саме найменування, як у введеного первісно.

При автоматичному заповненні суми модернізації розподіляються рівними частками за всіма об'єктами, переліченими в табличній частині.

Якщо модернізуються (реконструюються) об'єкти, для яких амортизація нараховується пропорційно до випущеної продукції (робіт, послуг), то необхідно зазначити загальний обсяг випуску продукції (робіт, послуг) з урахуванням модернізації (реконструкції) об'єктів.

Під час проведення документа ці відомості записуються в регістр і використовуються документом "Закриття Місяця" під час нарахування амортизації в місяці, наступному за місяцем відображення модернізації.
