Документ "Зміна параметрів нарахування амортизації НМА"

Документ "Зміна параметрів нарахування амортизації НМА" призначений для відображення змін у регістрі відомостей про нематеріальні активи для цілей управлінського та бухгалтерського обліку.

До документа вносяться нові відомості про нематеріальні активи (наприклад, новий строк корисного використання в разі його зміни, вартість для нарахування амортизації, обсяг продукції (робіт), спосіб нарахування амортизації).

Для більш швидкого заповнення табличної частини документа необхідно скористатися кнопкою "Підбір".

Після формування списку нематеріальних активів необхідно скористатися кнопкою "Заповнити" для заповнення табличної частини інформацією про нематеріальні активи за даними обліку, що існують на момент введення документа.

Під час проведення документа ці відомості записуються в регістр і використовуються документом "Закриття місяця" під час нарахування амортизації в місяці, наступному за місяцем зміни параметрів.

Цей документ не формує жодних проводок, він лише змінює значення відповідних ресурсів регістрів відомостей, що зберігають інформацію про нематеріальні активи.

Для зміни інших характеристик обліку нематеріальних активів (наприклад - способу відображення витрат з амортизації) використовуються інші документи - "Зміна способів відображення витрат з амортизації НМА"...
