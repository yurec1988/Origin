Документ "Модернізація та ремонт ОЗ"

Документ "Модернізація та ремонт ОЗ" призначений для відображення в обліку модернізації (реконструкції, капітального ремонту) та поточного ремонту основних засобів для цілей бухгалтерського та податкового обліку.

У шапці документа вносять відомості про об'єкт будівництва, з якого списують витрати на поліпшення, для бухгалтерського і податкового обліку - рахунок обліку витрат, а також суми модернізації, окремо для кожного з видів обліку.

Суму поліпшення можна отримати автоматично - при натисканні кнопки "Розрахувати суми" суми модернізації заповняться автоматично за даними обліку на момент формування документа. За необхідності ці суми можна відкоригувати вручну.

У табличній частині "Основні засоби" зазначаються об'єкти основних засобів, які модернізуються (реконструюються, ремонтуються).

Для більш швидкого заповнення табличної частини документа необхідно скористатися кнопкою "Підбір".

Після формування списку основних засобів необхідно скористатися кнопкою "Заповнити" для заповнення табличної частини інформацією про об'єкти основних засобів за даними обліку, що існують на момент введення документа, а також для розподілу сум модернізації.

Для швидкого заповнення табличної частини однотипними об'єктами основних засобів, що мають однакові найменування, слід ввести в табличну частину хоча б один такий об'єкт. Потім слід скористатися кнопкою Заповнити в командній панелі табличної частини. При виборі у випадаючому меню пункту За найменуванням таблична частина буде заповнена об'єктами основних засобів, що мають таке саме найменування, як у введеного спочатку.

При автоматичному заповненні суми поліпшення розподіляються рівними частками за всіма об'єктами, переліченими в табличній частині.

Якщо модернізуються (реконструюються, ремонтуються) об'єкти, для яких амортизація нараховується виробничим методом, то необхідно зазначити загальний обсяг випуску продукції (робіт, послуг) з урахуванням модернізації (реконструкції) об'єктів.

Під час проведення документа ці відомості записуються в регістр і використовуються документом "Закриття Місяця" під час нарахування амортизації в місяці, наступному за місяцем відображення модернізації.
