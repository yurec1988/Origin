Документ "Довідка про доходи"

Документ "Довідка про доходи" дає змогу формувати та редагувати для працівників організацій довідки про суми доходів та утримань за довільний період часу одного з таких видів:

  • довідка у вільній формі - не регламентована форма, що використовується для різних цілей;
  • довідка для розрахунку виплат із соціального страхування - за формою, затвердженою Постановою Кабінету Міністрів України від 26.09.2001 р. № 1266, у редакції постанови Кабінету Міністрів України від 26.06.2015 р. № 439;
  • довідка для розрахунку пенсії - за формою, затвердженою Постановою правління Пенсійного фонду України від 25.11.2005 р. № 22-1;
  • довідка для оформлення субсидії - за формою, затвердженою Наказом Міністерством праці та соціальної політики України від 27.08.2004 р. № 192, у редакції Наказу Міністерства соціальної політики України від 05.06.2015 р. № 591.

    Застарілі форми довідок:

  • довідка для призначення допомоги по непрацездатності - за формою, затвердженою Постановою Кабінету Міністрів України від 26.09.2001 р. № 1266;
  • довідка для призначення допомоги по безробіттю - за формою, затвердженою Постановою Кабінету Міністрів України від 26.09.2001 р. № 1266;
  • довідка для оформлення субсидії - за формою, затвердженою Наказом Міністерства праці та соціальної політики України від 27.08.2004 р. № 192.
