Документ "Партія"

Допоміжний документ, який не робить жодних проводок, призначений для ведення ручного обліку за партіями, тобто для організації субконто "Партія" на рахунках бухгалтерського обліку.

Реквізити необхідні для заповнення:

  • Організація
  • Контрагент - постачальник партії товарів або матеріалів;
  • Договір - договір поставки партії товарів або матеріалів;
