Настройка панелі користувача

Період

На формі вказуються ознаки виведення стандартних сторінок. "Період" - обмеження на список вибору Стандартних періодів або Стандартної дати початку.

На закладці період вказуються періоди, які будуть доступні в списку вибору періодів для стандартної дати початку або стандартного періоду. У разі вимкненого прапорця доступних періодів до списку вибору не потраплять усі варіанти, що включають цей доступний період. Наприклад, якщо зняти прапорець із "Попередній", до списку вибору не потраплять варіанти "Попередній рік", "Попереднє півріччя", "Попередній квартал" тощо. Аналогічно з періодичністю. Якщо відключити, наприклад, місяць, то зі списку вибору будуть виключені всі варіанти, що включають місяць. Якщо прапорець довільний період не виставлено, користувач зможе обирати дату тільки зі списку вибору, а вручну вводити дату(дати) не зможе.


Стандартні закладки

"Параметри" - у разі увімкненого прапорця на панелі користувача відображається табличне поле з доступними для користувача параметрами звіту (якщо є хоча б один параметр), "Відбір" - на панелі користувача відображатиметься табличне поле з відбором, що доповнюватиметься до відбору, зазначеного у варіанті звіту, "Сортування" - відображення на панелі користувача табличного поля із сортуванням, що додаватиметься до сортування, вказаного для варіанта звіту.

Швидкі відбори

Зазначаються в окремій табличній частині.

Опис колонок таблиці швидкі відбори:

  • Поле - поле, за яким буде здійснюватися відбір
  • Вид відбору - доступні такі види відбору: список, довгий список, значення, прапорець + значення, прапорець.
  • Вид порівняння - вказується вид порівняння, який буде підставлятися під час відбору. Для списків значення за замовчуванням - У списку, для інших - Дорівнює. Якщо поле містить тип - ієрархічний довідник, види порівняння будуть У списку за ієрархією і В ієрархії відповідно.
  • Варіант виключити - чи доступний вибір "Виключити вибрані" у швидкому відборі Список або Довгий список.
  • Розташування - доступні такі варіанти: на окремій сторінці (буде створено нову сторінку), на тій самій (швидкий добір відобразиться на тій самій сторінці, на якій і попередній швидкий добір, на додатковій сторінці - усі добори з таким значенням буде відображено на окремій сторінці із заголовком Добори.
  • Представлення - вказується рядок, який відображатиметься для представлення відбору - наприклад, для списків із розташуванням на новій сторінці - у вигляді заголовка сторінки, для прапорців - у вигляді заголовка прапорця.
  • Зберігати список - Для відбору виду Список і Довгий список можливість збереження користувачем списку значень, які можна завантажувати в інших звітах і варіантах для таких самих полів у відборах.
  • Використання - можливість задати значення прапорця або обраної умови відбору для списку за замовчуванням.
  • Значення - значення за замовчуванням для швидкого відбору або значення для швидкого відбору - прапорець.
