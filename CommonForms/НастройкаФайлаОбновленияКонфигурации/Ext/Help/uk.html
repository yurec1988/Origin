Форма "Настройка файлу оновлення конфігурації"

За допомогою цієї форми можна налаштувати формування bat-файлу автоматичного оновлення конфігурації для вузлів розподіленої інформаційної бази.

Форма призначена для редагування константи "Настройка файлу оновлення конфігурації". Константа використовується механізмом автоматичного обміну даними.

Під час обміну даними між вузлами розподіленої інформаційної бази даних можливий випадок, коли файл обміну містить інформацію про зміну метаданих конфігурації. Для внесення змін до інформаційної бази з такого файлу можна вчинити так. Після читання з файлу закрити програму, запустити конфігуратор, прийняти зміни метаданих, які було внесено, знову завантажити програму і виконати повторне читання даних (під час першого читання даних автоматично неможливо застосувати всі зміни для поточної інформаційної бази, оскільки файл обміну містить інформацію про зміну метаданих).

Для автоматизації такого процесу й існує ця настройка. Після проведення обміну даними може бути створено bat-файл, який виконує такі дії:

1. Завершення роботи всіх користувачів із програмою (виконується під логіном адміністратора інформаційної бази)

2. Запуск конфігуратора і застосування всіх змін (виконується під логіном адміністратора інформаційної бази)

3. Дозвіл роботи користувачам із програмою (виконується під логіном адміністратора інформаційної бази)

4. Запуск програми під користувачем, під яким здійснювався обмін даними

Існує 2 варіанти настройки такого bat-файлу:

1. Настройка з подальшим автоматичним формуванням bat-файлу

2. Настройка зі збереженням тексту bat-файлу

Під час настройки bat-файлу, текст якого буде згенеровано автоматично під час роботи програми, є такі настройки:

1. адміністратор інформаційної бази даних - логін адміністратора інформаційної бази даних

2. ім'я файлу для запису помилок - файл, у який будуть записуватися всі помилки та повідомлення під час зміни конфігурації інформаційної бази

Під час настройки зі збереженням тексту bat-файлу необхідно вказати повний текст bat-файлу, який має створюватися для оновлення конфігурації.

Після виконання настройки є можливість подивитися сам bat-файл, який створюватиметься під час застосування змін до конфігурації.

Виконати дії з автоматичної зміни конфігурації можна у формі "Виконання обміну даними" під час натискання на кнопку "Застосувати зміни конфігурації"
