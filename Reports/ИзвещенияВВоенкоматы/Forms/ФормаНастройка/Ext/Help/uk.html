Настройка звіту

Елементи форми "Настройка" можна умовно розділити на такі групи: встановлення значень для відбору і сортування даних у звітах.

У звітах передбачено два види відбору: швидкий відбір і розширений відбір. Швидкий відбір здійснюється за конкретним списком об'єктів, строго визначеним для кожного виду звіту. Швидкий відбір вмикається за кнопкою "Відбір" у головній панелі управління звітом.

Розширений відбір дає змогу розширити список об'єктів для відбору, він доступний на закладці "Відбір" у діалоговому вікні "Настройка звіту".

Відбори взаємопов'язані між собою. Ті значення, які встановлені в параметрах швидкого відбору, автоматично відображаються в розширеному відборі. Якщо відбір встановлюється в діалоговому вікні настройок звіту, то встановлені параметри автоматично з'являються у швидкому відборі.

Принцип встановлення відбору однаковий, як для швидкого, так і для розширеного відбору. У звітах передбачено два варіанти відбору даних: відбір конкретного значення або множинний відбір.

Відбір конкретного значення для кожного аналітичного розрізу встановлює відбір за одним конкретним значенням об'єкта (позицією номенклатури, контрагента).

Множинний відбір дає змогу визначити для кожного аналітичного розрізу список елементів, за якими буде проведено відбір даних звіту. Таким чином, множинний відбір розширює можливості настройки порівняно з відбором конкретного значення.

Для відбору конкретного значення параметр "Тип порівняння" встановлюється "Дорівнює".
При множинному відборі списку значень необхідно встановити параметр "Тип порівняння" - "У списку".
У тому разі, якщо параметр "Тип порівняння" встановлено "Не дорівнює" або "Не в списку", то буде відібрано всі об'єкти, окрім зазначених конкретних значень або значень, зазначених у списку.

У разі відбору списку значень для підбору об'єктів відкривається додатковий діалог "Редагування списку значень". Підбір об'єктів у список значень здійснюється за допомогою кнопки "Підбір".
