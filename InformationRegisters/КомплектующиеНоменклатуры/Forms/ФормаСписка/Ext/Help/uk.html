Регістр відомостей "Комплектуючі номенклатури"

У регістр відомостей "Комплектуючі номенклатури" заноситься інформація про список комплектуючих для комплектів і наборів.

Для наборів використовується окремий вид номенклатури - набір, який встановлюється під час введення набору в довідник "Номенклатура". Для наборів не ведеться кількісний і вартісний облік, вони використовуються тільки для швидкого підбору списку комплектуючих, що входять до складу набору, в табличну частину документа. Як комплектуючі в наборі можуть бути вказані тільки товари, інші набори та послуги не можуть бути задані як комплектуючі для набору. До складу набору можуть входити товари з різними характеристиками, проте для самих наборів не ведеться облік за характеристиками.

Комплектом може бути будь-який товар, для якого заповнено список комплектуючих у регістрі відомостей "Комплектуючі номенклатури". Комплекти використовуються під час оформлення операцій комплектації (розукомплектації).

За комплектами ведеться облік за характеристиками. У довідник "Номенклатура" може бути введений один комплект, що має різні характеристики. Для кожного комплекту з конкретною характеристикою може бути визначений свій список комплектуючих з певними характеристиками.

Поле вибору "Характеристика комплекту" в регістрі відомостей дає змогу здійснювати відбір за складом комплектуючих, заданих для комплекту із зазначеною характеристикою.

Поле "Частка" в регістрі відомостей використовується для визначення частки вартості комплектуючого в загальній вартості комплекту при оформленні операції розукомплектації комплекту.
