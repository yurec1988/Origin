Регістр відомостей "Комплектуючі номенклатури"

У цьому регістрі зберігається список комплектуючих, визначених для комплекту або набору в довіднику "Номенклатура".

Список комплектуючих для набору використовується для швидкого заповнення інформації про складові набору в документ. Список комплектуючих для комплекту використовується під час оформлення операцій комплектації та розукомплектації. Комплектація і розукомплектація проводиться за допомогою документа "Комплектація номенклатури".
